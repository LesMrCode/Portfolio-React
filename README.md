# Portfolio-React

This is an online webpage to showcase who we are, our skills and our projects and serves as an online resume.

Technologies used: React,Vite,Tailwind CSS,Bootstrap and CSS

The neccesary tools were installed through the terminal on VSCode,eg...Node modules & Vite.

Features:
Clean commented code in React
Live deployment on Vercel & a Live demo
Button that is linked to CV
Various sections of the projects

File Structure:
 components/ 
 ├── Navbar.jsx 
 ├── Home.jsx  
 ├── About.jsx 
 ├── Skills.jsx  
 ├── Projects.jsx 
 ├── Contact.jsx 
 └── Footer.jsx 
 ├── App.jsx 
 ├── index.js
 ├── App.css 
 └── assets/ 

 The project setup included some of the following steps:

 Opening the terminal and using npm install to create the project.
 And then npm run dev to allow us to host the webpage locally while we build it before deploying.
 Additional materials like the node modules were also installed through the terminal, as well as Tailwind CSS & Bootstrap.
